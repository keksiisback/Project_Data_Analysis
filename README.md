## Project_Data_Analysis 

## Projektbeschreibung

Dieses Projekt beschäftigt sich mit der Analyse von Kundenbewertungen zu elektronischen Produkten mithilfe von Natural Language Processing (NLP).

Ziel ist es, wiederkehrende Themen in den Bewertungen zu erkennen und verschiedene Verfahren zur Textanalyse miteinander zu vergleichen.

Verwendet werden die Verfahren:
- Bag of Words (BoW)
- TF-IDF
- Latent Dirichlet Allocation (LDA)
- Latent Semantic Analysis (LSA)

## Voraussetzungen

Für die Ausführung werden benötigt:
- Python
- Anaconda
- Die verwendeten Python-Bibliotheken Pandas, spaCy und Scikit-learn

## Ausführung

1. Repository herunterladen oder klonen.
2. Den verwendeten Datensatz „Electronic Products“ herunterladen.
3. Die CSV-Datei im vorgesehenen Projektverzeichnis ablegen.
4. Die Python-Datei `Project_Data_Analysis.py` in Visual Studio Code oder einer anderen Python-Umgebung öffnen.
5. Das Skript ausführen.

Die benötigten Bibliotheken müssen vor der Ausführung installiert sein.

## Ergebnisse

Das Skript führt die Textvorverarbeitung, Vektorisierung und Themenmodellierung durch. Dabei werden die Ergebnisse von LDA und LSA ausgegeben und miteinander vergleichbar gemacht.
